# 大学生体测成绩计算器

College Fitness Score Calculator

纯前端 React + TypeScript + Vite 工具，用于录入大一到大四的体测数据，按性别、年级段和项目自动换算单项得分，并计算学年成绩与四年总评。

## 功能

- 男生：BMI、肺活量、50 米跑、坐位体前屈、立定跳远、引体向上、1000 米跑。
- 女生：BMI、肺活量、50 米跑、坐位体前屈、立定跳远、一分钟仰卧起坐、800 米跑。
- 支持大一、大二、大三、大四四个学年分别录入体测数据。
- 每个项目都支持两种录入方式：输入原始测试数据自动换算成绩，或直接输入项目得分；两种模式可以逐项目切换。
- 身高和体重用于计算 BMI；BMI 按一位小数标准化后评分。800/1000 米使用分钟和秒输入，内部存储为秒。
- 自动计算每个学年的体测成绩，并在四个学年完成后计算大学四年最终总评。
- 根据目标学年前的有效原始测试成绩提供大二、大三或大四趋势预测，默认目标为大四；预测不使用历年项目分数。
- localStorage 自动保存性别、四年数据、输入模式、原始值和直接得分；刷新页面后数据不会丢失，清空操作需要确认。
- 空白和 0 分严格区分；未完成学年不参与总评，并显示完成进度。

男生和女生体测数据采用独立档案保存。切换性别不会复用、转换或覆盖另一侧的体测记录。

旧版数据会自动迁移到其原记录性别对应的档案中。

## 计算公式

学年成绩为所有适用项目的 `项目得分 × 项目权重` 之和，所有单项成绩和学年成绩最高为 100 分。四年总评为：

```text
学年成绩 = Σ(项目得分 × 项目权重)
前三年平均 = (大一 + 大二 + 大三) / 3
最终成绩 = 前三年平均 × 50% + 大四 × 50%
```

内部计算不提前四舍五入，最终展示时保留两位小数。四年未完成时只显示当前已完成部分，不生成最终分数。

## 趋势预测

趋势预测区域默认收起，用户可主动展开并选择“大二”“大三”或“大四”作为预测目标，默认目标为大四。每个目标只读取目标学年之前的当前有效原始测试数据：预测大二只用大一，预测大三只用大一和大二，预测大四只用大一至大三。目标学年和未来学年的真实数据不会进入模型。直接输入项目得分的年份不能参与预测；切换到直接得分模式后，即使旧的原始值仍保留，也不会被趋势模型读取。

模型按可用历史点数量选择，均为等权、可解释的简单模型：

```text
1 个历史点：center = F_hold = x1
2 个历史点：F_hold = x2，F_recent = x2 + (x2 - x1)
             center = (F_hold + F_recent) / 2
3 个历史点：F_hold = x3，F_recent = x3 + (x3 - x2)
             F_long = x3 + (x3 - x1) / 2
             center = (F_hold + F_recent + F_long) / 3
```

页面同时展示由当前目标子模型的最小值和最大值形成的“趋势情景范围”。它不是统计置信区间，也不是 95% 区间或准确率承诺。预测原始值会按项目的记录精度标准化后，再交给目标学年的正式评分表计算预测项目分；只有全部适用项目均可预测时，才生成对应目标学年成绩。只有目标为大四且前三个真实学年成绩完整时，才继续计算预测毕业体测总评。

BMI 的历史序列由每学年的身高和体重计算得到，趋势层只预测 BMI 数值，不预测未来身高或体重。所有预测结果都是根据当前数据实时派生的参考信息，不会写入大四真实成绩或新增 prediction localStorage 数据。

## 评分规则

评分表集中在 `src/data/scoringRules/`，由以下四个规则集独立维护：

- `maleLower.ts`：男生大一/大二
- `maleUpper.ts`：男生大三/大四
- `femaleLower.ts`：女生大一/大二
- `femaleUpper.ts`：女生大三/大四

除 BMI 外的项目评分规则和权重来自项目内学校正式资料：[docs/scoring-standards/](docs/scoring-standards/)。BMI 使用教育部《国家学生体质健康标准（2014 年修订）》大学生 BMI 标准，根据身高和体重计算后，先四舍五入到 1 位小数再评分；男生和女生的正常范围不同。当前学校规则不使用任何附加分，所有项目得分和学年成绩均为 0～100 分。如果学校使用不同版本，只需替换规则模块中的阈值和 `metadata.ts` 来源，不需要修改评分引擎或 React 组件。

## 项目结构

```text
src/
  components/       页面组件与项目输入卡片
  data/scoringRules/四套评分表与来源元数据
  hooks/            React 状态与 localStorage 生命周期
  types/            体测领域类型与评分类型
  utils/            BMI、时间、校验、评分和汇总纯函数
  test/             Vitest 测试环境配置
  **/*.test.ts(x)   单元测试和界面测试
  App.tsx           页面组合
  styles.css        响应式工具型界面
docs/
  scoring-standards/学校正式评分资料
public/             静态资源
package.json        依赖与开发命令
```

## 环境要求

- Node.js：20.19.0 及以上的 20.x，或 22.12.0 及以上。当前 Vite 版本的运行要求如此。
- npm：项目未声明单独的 npm 版本要求，使用与 Node.js 匹配的 npm 即可。
